Only public textile product/market context is passed to appropriate textile pages; private forms are never included in navigation.

Existing analytics/ads retain their prior policies and behavior; this redesign does not claim to remove existing external tracking. All official-source and disclaimer content remains. The actual public provider dataset remains empty until real approvals.

Native tool controls and print layouts are preserved. Historical directories blocked in robots.txt are still publicly accessible if deployed: robots rules are not authentication or a privacy boundary.
