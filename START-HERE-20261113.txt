HOW TO APPLY ON YOUR MAC
1. Extract this ZIP.
2. Back up your existing repository, including any uncommitted files.
3. Compare your current git rev-parse HEAD with the baseline above. If newer, merge the changed files instead of overwriting newer work.
4. Copy website/ contents into your existing repository root; preserve its .git folder. No deletions are required.
5. Review git diff and git status. Run python3 tools/check_site_links.py and python3 tools/verify_redesign.py.
6. Preview with python3 -m http.server 8000, open http://localhost:8000 and check the English/Tamil homepages, Home button and notices. Stop with Ctrl+C.
7. Commit reviewed changes and push using your existing GitHub/Cloudflare publishing workflow.
